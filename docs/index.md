## Works with the LLM you choose

Septum connects to Anthropic, OpenAI, OpenRouter, or a local Ollama model. You switch providers from the dashboard, and the masking pipeline stays the same.

Septum is open source under the MIT License. Start with the [Installation Guide](./installation.md) to run it with Docker, or read the [Features reference](./features.md) for the detection pipeline, regulation packs, and API.
